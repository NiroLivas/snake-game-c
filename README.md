# CLI-Based Snake Game in C
A classic Snake game built in C and played directly in the command-line interface (CLI).

## Features
• WASD and ARROW KEYS control<br>
• Highscore Detection<br>
• Speed Configuration<br>

## What I Learned
This project helped me practice:<br>
• Working with C-specific memory and data-management<br>
• Saving and loading game data using file I/O<br>
• Handling real-time keyboard input using a separate input thread<br>
